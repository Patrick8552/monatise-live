# Crypto Response Formatter
Show asset, decision, regime, conviction, quality, reason, evidence, expiry, and valid levels. CoinGlass is the only permitted market-data provider; report provider unavailable if CoinGlass data is absent. End channel output with `Analysis only. No trade was executed.` Present NO_TRADE as completed and never use placeholder language.
