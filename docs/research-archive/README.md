These files preserve original design decisions and preparation artifacts. They
are documentation, not active policies, completed backtests or current readiness
certificates. Their bytes match their original SHA-256 entries in
[the design manifest](../continuity/archived-design-manifest.json).

* `gold-h1-fib-specification.md`: 10 October 2026 H1 revision. The later frozen
  F0 implementation is on `codex/gold-h1-fib-f0-shadow` at `f1de9d46`.
  GIL annotation/confluence/veto/cap/partial arms remain proposals; preserving
  this specification does not implement or authorize them. The superseded M15
  revision remains private historical context; it is not an available selector.
* `xauusd-fib-study-protocol.json` and `xauusd-fib-study-readme.txt`: 7 October
  preparation for a 1.618/2.0/2.618 comparison. Its historical "runner missing"
  statements refer to that date. Subsequent isolated broker/GC research is
  documented separately; this study has no authentic performance results.
* `xauusd-fib-study-empty-ledger.csv`: original header only, with zero observations.

Use [development continuity](../monatise-development-continuity.md) for implemented
